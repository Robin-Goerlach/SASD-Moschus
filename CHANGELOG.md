# Changelog

All notable user-visible changes to SASD Moschus will be documented here.

The format follows the intent of Keep a Changelog. Product versions will use
semantic versioning once stable public APIs exist. Format, product and language
epochs remain separate concepts.

## [Unreleased]

### Added

- project repository and MIT licence;
- Lastenheft and detailed technical Pflichtenheft;
- comprehensive architecture baseline;
- milestone roadmap from the 1990 format epoch through C++20;
- format coverage matrix and source notes for Kussmann and Born;
- repository layout for C89, C++, C# and Java libraries;
- C++ converter, specification, conformance, corpus and example placeholders;
- contribution, governance, security, support and release documentation;
- glossary, format-specification template, conformance-manifest specification,
  source/corpus policy and ADR process.

### Known limitations

- no file format is production-ready yet;
- exact retro compiler versions remain an ADR decision;
- coverage entries are research candidates, not support claims;
- public library APIs and package formats are not yet frozen.

## Release entry template

For each release add:

```markdown
## [X.Y.Z] - YYYY-MM-DD

### Added
### Changed
### Deprecated
### Removed
### Fixed
### Security
### Format coverage
### Toolchain coverage
### Known limitations
```

Release notes must link the exact tag, checksums and acceptance evidence where
applicable.
