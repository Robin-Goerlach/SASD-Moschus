# Source notes

This directory indexes research sources used to understand historical file
formats. Source notes document what was consulted, not copied content.

## Initial references

- [`kussmann-1989.md`](kussmann-1989.md) — Ralf Kussmann,
  *Dateiformate und Konvertierung*, DATA BECKER, 1989.
- [`born-1992.md`](born-1992.md) — Günter Born,
  *Referenzhandbuch Dateiformate: Grafik, Text, Datenbanken,
  Tabellenkalkulation*, Addison-Wesley, 1992 edition.

## Required fields for a source note

- stable source ID;
- complete bibliographic citation;
- edition/revision and publication date;
- ISBN/standard/document number where available;
- source/evidence class;
- formats and versions discussed;
- exact pages/sections consulted;
- claims used by Moschus;
- known omissions, errors or contradictions;
- copyright/access notes;
- related specifications and test evidence;
- reviewer and review date.

## Research method

1. use a secondary source to identify structures and terminology;
2. locate primary manufacturer/standards documentation where possible;
3. compare version and date claims;
4. create lawful synthetic fixtures;
5. compare with named historical applications when available;
6. mark conclusions as normative, secondary, empirical, derived or unresolved;
7. update specifications, not just informal notes.
