# Research sources

This directory records the provenance of technical format information used by
SASD Moschus.

A source note should contain:

- complete bibliographic or standards information;
- the exact edition or revision;
- the relevant format versions and page ranges;
- whether a statement is normative, descriptive, inferred, or experimentally
  verified;
- known contradictions with other sources;
- redistribution restrictions;
- open questions that require test files or additional references.

Source notes summarise facts needed to implement interoperable software. They
must not reproduce substantial copyrighted text, illustrations, listings, or
bundled programs.
