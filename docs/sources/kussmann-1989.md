## Intended role in Moschus

This book complements structural references with contemporary application
behaviour: import and export routes, interface limitations, and practical data
exchange between packages such as dBASE IV, Microsoft Word, Multiplan, Excel,
Lotus 1-2-3, Microsoft Chart, IBM Text 4, PageMaker, Ventura Publisher, and
Freelance Plus.

Its technical format overview includes dBASE IV, Microsoft Word 4.0, SYLK,
ASCII DELIMITED, ASCII SDF, and DCA/RFT.
